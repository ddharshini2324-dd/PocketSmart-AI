# PocketSmart AI: Smart Budget Planner

PocketSmart AI is a Generative AI-powered web application built with FastAPI, Jinja2 Templates, SQLite, and Google Gemini API.

## Features
- **Authentication**: Secure Register/Login system.
- **Home Interior Planner**: Intelligent allocation for furniture, lights, and fans with e-commerce links.
- **Party Planner**: Event budget breakdown with links to Swiggy, Zomato, OYO, and more.
- **Jewelry Planner**: Multimodal style analysis with outfit image inputs.
- **History Tracking**: Live user query logging.

## Tech Stack
- FastAPI, Jinja2, SQLite, Python 3.10+, Gemini 1.5 Flash API
